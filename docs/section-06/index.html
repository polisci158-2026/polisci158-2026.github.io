Recap: learning from rewards

The ideas you'll use today. Your TA will go over them at the start of section; come back here if you need a reminder.

1 · The loop

Agent sees the state→picks an action→the game changes→a reward→ repeat

In supervised learning (Section 2) every example comes with the right answer. In reinforcement learning nobody gives the right move. The agent gets only a number, the reward, sometimes long after the move that earned it, and has to work out which moves lead to more of it. What it learns is a policy: which action to take in each state.

2 · Q-learning: a table of expectations

Today's agent keeps a table. For every state and every action it stores a number Q: how much total reward it expects if it takes that action there and plays well afterwards. At first every Q is 0. After each move it nudges the number toward what just happened:

new Q = old Q + α × ( reward + γ × best Q of the next state − old Q )

  • α (learning rate): how far to move toward the new evidence each time. Today: 0.2.
  • γ (discount): how much a reward one step later counts compared with one now. 0.95 means patient; 0.5 means short-sighted.
  • Rewards flow backward: once the square next to the goal has a high Q, the square before it learns from that, and so on back to the start.

3 · Explore or exploit?

If the agent always takes the move it currently rates best (exploit), it never finds better ones. If it always moves at random (explore), it never uses what it learned. The usual fix, ε-greedy: with chance ε (say 20%) try a random move, otherwise take the best one.

4 · You get what you reward, not what you want

The reward is the only thing the agent knows about your goal. If the reward can be earned in a way you didn't intend, a good learner will find it. This is called reward hacking or specification gaming. A famous case: OpenAI (2016) trained an agent on the boat-racing game CoastRunners, rewarded for hitting targets along the course. It learned to circle a lagoon hitting the same respawning targets, on fire and going the wrong way, and scored higher than human players without ever finishing the race.

It's the same problem as Goodhart's law: when a measure becomes a target, it stops being a good measure. And it's not just games. The reward models in Section 5 (RLHF) are rewards too, and feeds that learn to maximize clicks or watch time are optimizing a number that stands in for what people want.

Try it: which of these is reward hacking?

A cleaning robot rewarded for "no mess visible to its camera" learns to cover its camera.

The reward measured what the camera saw, not how clean the room was.

A chess agent rewarded for winning finds an opening no human had played.

Surprising isn't the same as unintended: winning is exactly what we wanted.

A news feed rewarded for time spent learns to show more outrage, because people keep scrolling.

Time spent was a stand-in for "people value this." The agent maximized the stand-in.

A chatbot rewarded by people's ratings learns to agree with whatever the user believes.

People rate agreement highly, so the reward model does too: sycophancy. You saw reward models in Section 5.

      Words you'll need
      
    
      
      
      Agent
      The learner that chooses actions.
      
      
      State
      What the agent can see when it chooses: here, its square and how long until the TV studio reopens.
      
      
      Action
      A move it can make: up, down, left, right.
      
      
      Reward
      The number the game gives after each action. The only signal of what we want.
      
      
      Episode
      One whole game, from start to finish.
      
      
      Policy
      The agent's rule for which action to take in each state.
      
      
      Q-value
      The total future reward the agent expects from taking an action in a state.
      
      
      Learning rate (α)
      How far each update moves a Q-value toward the new evidence.
      
      
      Discount (γ)
      How much later rewards count compared with immediate ones.
      
      
      Exploration (ε)
      The share of moves the agent makes at random while training, to find better options.
      
      
      Reward hacking
      Earning a high reward in a way the designer didn't intend. Also called specification gaming.
      
      
      Goodhart's law
      When a measure becomes a target, it stops being a good measure.
