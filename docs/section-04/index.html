Recap: how a language model writes

The ideas from Session 7 you'll use today, with more detail on what happens inside the model. Your TA will go over them at the start of section; come back here if you need a reminder.

1 · From text to next-token chances

Pre-trainingHuge amounts of text → guess the next token, trillions of times; adjust the weights after each guess → a base model: a text predictor
Post-trainingexample conversations, people's rankings → a chatbot

A token is a word or a piece of a word. Given the text so far, the model gives every token in its vocabulary a chance of coming next ("The sky is" → blue 38%, clear 20%, …). It picks one, adds it to the text, and repeats. Temperature sets how adventurous the pick is.

2 · Inside a transformer

Inputiamworriedthataiwill
1 · EmbedEach token becomes a list of numbers (a vector), plus a signal for its position. Words used in similar ways get similar vectors.
2 · AttentionEach token looks back at the tokens before it and pulls in information from the ones that matter for it.
3 · Feed-forwardEach token's vector goes through a small neural network on its own: where much of what the model "knows" is stored.
Steps 2–3 make one layer. Stack many layers: 2 in today's tiny model, 96 in GPT-3.
4 · PredictThe last token's final vector is compared with every word in the vocabulary → a score for each → softmax turns scores into chances that add up to 100%.

During training, every position predicts its own next token at the same time. Processing the whole text in parallel, instead of one word after another, is a big reason transformers (Vaswani et al., 2017) could be trained at scale.

3 · Attention, step by step

Before attention, the vector for "will" is the same in every sentence. Attention lets it take in its context. Each token makes three vectors from its own numbers:

Query"What am I looking for?"
Key"What do I contain?"
Value"What I pass on if you pick me."
  1. Compare the last token's query with every earlier token's key (a dot product): a score for each.
  2. Softmax the scores into attention weights that add up to 1. A token can only look back, never ahead.
  3. Add up the earlier tokens' values, each multiplied by its weight. That mix updates the token's vector.

A real example from today's tiny transformer (layer 2, head 2)

From "will", almost all the attention goes to "worried". That's how the model "knows" the next word should be take, not help. Each layer has several heads, each with its own queries and keys, so different heads can look for different things.

Why it matters, and what it costs. A model that counts word pairs sees only the last word or two; attention can use anything in the context window. But every token is compared with every earlier token, so the work grows with the square of the text length. And taking text in is not the same as using it well: in one test, GPT-3.5 answered correctly 76% of the time when the document with the answer came first, but 54% when it sat in the middle (Liu et al., 2024).

4 · Scale

Ten times more computing, model size or training text cut the prediction error by about 11%, 16% and 20% (Kaplan et al., 2020), steadily enough to forecast GPT-4's error from much smaller models. But scale fixes some errors and not others.

5 · Why models hallucinate

Where it comes from. Pre-training shows the model only fluent text, with no examples marked "false". Patterns that repeat, like spelling or matching parentheses, get learned, and those errors fade with scale. But an arbitrary, rarely written fact (someone's birthday, a dissertation title, one subgroup's number in one poll) can't be predicted from patterns. The model still produces the most likely-sounding answer.

Try it: which errors should fade as models get bigger?

Misspelling "government"

Spelling follows patterns seen millions of times. These errors disappear with scale.

The birthday of a county election official

Arbitrary and rarely written down. No pattern predicts it, so a model that answers anyway is guessing.

"The senators votes against the bill"

Grammar is a regular pattern. Large models almost never make this mistake.

The share of Republicans "more concerned than excited" about AI in June 2026

One number, from one poll, possibly after the model's training text was collected. You'll test this in Part 3.

Why it persists: grading rewards guessing. Most tests score a right answer 1, and both a wrong answer and "I don't know" 0. Then guessing never scores less than admitting uncertainty: a guessed birthday has a 1-in-365 chance; "I don't know" has none. Leaderboards that rank models by accuracy alone reward models that guess (OpenAI, 2025; Kalai et al., 2025). Part 2 lets you play that game.

      Words you'll need
      
    
      
      
      Token
      A word or a piece of a word: the unit a language model reads and writes.
      
      
      Embedding
      The list of numbers (vector) that stands for a token inside the model.
      
      
      Attention
      The step where each token compares its query with earlier tokens' keys, turns the scores into weights that add up to 1, and takes in a weighted mix of their values.
      
      
      Head
      One attention pattern. Each layer has several heads, each free to look for something different.
      
      
      Layer
      Attention followed by a feed-forward network. Models stack many layers.
      
      
      Softmax
      Turns a list of scores into chances that are all positive and add up to 1.
      
      
      Context window
      The text the model can see when it predicts: the whole chat so far, plus anything a search pasted in.
      
      
      Temperature
      How adventurous the pick is. Low: almost always the top token. High: less likely tokens get picked more often.
      
      
      Prediction error
      How surprised the model is, on average, by each next word of text it never saw. Lower is better.
      
      
      Hallucination
      A plausible but false statement made with confidence: a made-up number, quote or citation.
      
      
      Abstain
      Decline to give a specific answer ("I don't know").
      
      
      Silicon sample
      Survey respondents simulated by a language model instead of real people.
