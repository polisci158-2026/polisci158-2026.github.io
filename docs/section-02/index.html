Recap: how machines learn

The five ideas from Session 3 that you'll use today. Your TA will go over them at the start of section; come back here if you need a reminder.

1 · Where machine learning fits

AI systems that mimic human reasoning and decisions
Machine learning learns rules or patterns from data
Deep learning machine learning with many-layered neural networks
Generative AI learns what data look like, to make new content
LLMs generative AI built on transformers, trained on huge amounts of text

2 · Programming vs. machine learning

ProgrammingRules (a person writes them) + Data → Answers
Machine learningData + Answers (labels) → A rule learned from the examples

3 · Three kinds of learning

Try it: which kind of learning is each task?

Predict whether a bill will pass, from 10,000 past bills marked passed or failed.

Every example comes with the answer (passed or failed). That's supervised learning, and it's what you'll do in Part 1.

Group legislators who vote alike, with no labels given.

There are no answers to learn from, only patterns to find. That's unsupervised learning.

Improve a chatbot using people's thumbs-up and thumbs-down on its answers.

The model acts, then gets a reward or penalty. That's reinforcement learning. You'll see it again in the post-training session.

Flag benefit claims for review, learning from past claims marked correct or incorrect.

Supervised again: the past claims are labeled. But who wrote those labels? Keep that question in mind for Part 2.

4 · Overfitting: training error vs. new-data error

A flexible enough model can memorize its training examples, noise and all, so its training error keeps falling. What matters is the error on examples it has never seen: the test error. That falls at first, then rises once the model starts memorizing. This is overfitting. That's why we always hold back some data to test on.

5 · Neurons and gradient descent

A neuron takes a weighted sum of its inputs, then bends it. A network stacks layers of neurons. The weights are the numbers it learns. It learns them by gradient descent:

  1. Start with random weights.
  2. Measure the error (the loss) on the training examples.
  3. Change every weight a little in the direction that lowers the error.
  4. Repeat. One pass through all the training examples is one epoch.

Part 1 · Will the bill get out of committee?

Each dot is a bill in a made-up legislature. The network sees two numbers about each bill:

  • Sponsor's ideology (left to right): how far the sponsor is from the chamber's median member.
  • Majority-party cosponsors (bottom to top): what share of the bill's cosponsors come from the majority party.

Its job is to predict whether the bill got out of committee or died in committee. The background shows the network's guess for every possible bill. Test accuracy is the share of 1,000 new bills it gets right.

The data are simulated. In this made-up chamber, moderate sponsors need less majority support, and sponsors far from the median need a lot. The network doesn't know that rule; it has to learn it from the dots.

Part 2 · Which benefit claims get flagged?

A fictional benefits agency wants a model to pick which claims get a fraud check. It can check 10% of claims. The model learns from 2,000 past claims, each marked in the agency's records as fraud or not fraud. It's then tested on 2,000 new claims, and the 10% with the highest risk scores are flagged.

    Words you'll need
    
    
    
      
    Training data
    The examples the model learns from.
    
      
    Test data
    Examples held back to check the model on cases it has never seen.
    
      
    Label
    The answer attached to an example (passed / failed, fraud / not fraud). Someone, or some process, produced it.
    
      
    Loss
    The model's error, as one number. Lower is better. Here: cross-entropy, which punishes confident wrong answers hardest.
    
      
    Accuracy
    The share of examples the model gets right.
    
      
    Weight
    A number inside the network that it adjusts while learning.
    
      
    Epoch
    One pass through all the training examples.
    
      
    Overfitting
    Fitting the training data so closely, noise included, that the model does worse on new data.
    
      
    Proxy
    An input that stands in for another one, like postcode standing in for citizenship.
